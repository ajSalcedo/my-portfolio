# Personal Portfolio

A simple mobile-first responsive portfolio inspired by the supplied reference image, using a warm brown/beige palette.

## Folder structure

```text
personal-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
    ├── profile.jpg
    ├── about.jpg
    ├── project-1.jpg
    ├── project-2.jpg
    └── project-3.jpg
```

## Add your images

Put your own JPG/PNG/WebP files in `images/` using the names above.

You can also change the filenames in `index.html` if you prefer.

## Add your social links

Open `index.html` and replace the `#` in the Facebook, Instagram, and TikTok links with your profile URLs.

Example:

```html
<a href="https://www.facebook.com/yourusername" ...>
```

## Personalize the text

Search `index.html` for:
- `Your Name`
- `Creative Mind`
- `Project One`
- `Project Two`
- `Project Three`
- `youremail@example.com`

Replace them with your information.

## Run locally in VS Code

The easiest option is the **Live Server** extension:
1. Open this folder in VS Code.
2. Install Live Server.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website also works as plain HTML/CSS/JS without a backend.

## Free GitHub Pages hosting

1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Make sure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save.

Your portfolio will then be available through your GitHub Pages address.
